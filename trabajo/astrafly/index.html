AstraFly

Sistema empresarial de gestión aérea: web, escritorio y API propia.

C#.NETWebAPISQL ServerWinFormsLog4net

Resumen

ASTRAFLY es una solución de software empresarial desarrollada como proyecto final para Desarrollo de Software III, enfocada en la gestión eficiente de vuelos y operaciones de una empresa aeronáutica: vuelos, reservas, clientes, destinos, tripulación y aeronaves, con una experiencia clara para controlar procesos clave en tiempo real.

Se desarrolló en C# sobre .NET Framework con arquitectura en capas. Incluye una app de escritorio en Windows Forms y una interfaz web en .NET, HTML y CSS, ambas sincronizadas en tiempo real mediante una WebAPI propia. Los datos se protegen en SQL Server con cifrado a nivel de base de datos, y Log4net registra la trazabilidad del sistema.

Rol

Diseño e implementación full-stack

Multiplataforma

Escritorio (WinForms) y web comparten la misma WebAPI, sincronizando datos entre ambas superficies en tiempo real.

Datos y seguridad

SQL Server con cifrado a nivel de base de datos para proteger información sensible de clientes y usuarios del sistema.

Trazabilidad

Log4net para registro de eventos, y manejo de archivos JSON para configuración dinámica y exportación de datos.
