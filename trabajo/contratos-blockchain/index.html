Contratos + Blockchain

Resumen

Este proyecto lleva un problema real —la gestión de contratos digitales— a una solución moderna y verificable, combinando una aplicación web completa con registro inmutable en blockchain. En vez de depender solo de una base de datos tradicional, el sistema incorpora una prueba criptográfica que fortalece la trazabilidad, reduce disputas y eleva la confianza entre las partes.

En sistemas tradicionales, el historial de un contrato puede alterarse y la validación depende de un “tercero de confianza”. Aquí el contrato vive en el flujo normal de una aplicación empresarial, pero al alcanzar un estado formal —cuando todas las partes aceptan— se registra en una red blockchain, creando evidencia verificable (timestamp, estado y referencia on-chain) que aporta no repudio, auditoría y transparencia.

Rol

Full-stack + smart contract

Ciclo de vida completo

Creación, edición, revisión, aceptación o rechazo y seguimiento — multiparte, con invitación de participantes y control de decisiones por cada contraparte.

Registro on-chain

Al finalizar el proceso, un smart contract en Solidity (desplegado y probado con Hardhat) registra el contrato y expone su estado on-chain, con hash de transacción verificable.

Arquitectura híbrida

SPA en React + TypeScript (Vite), API REST en Node.js + TypeScript + Express, persistencia en SQL Server y capa blockchain con Solidity + Hardhat — un ejercicio real de arquitectura Web2 + Web3.
