Kit de Seguridad Ofensiva

Herramientas de pentesting y monitoreo construidas para un entorno de laboratorio controlado.

PythonScapyParamikoTkinterpsutil

Resumen

Dos herramientas educativas pensadas para entornos controlados de laboratorio, construidas con Tkinter sobre Python. El “Kit de Pruebas de Seguridad” simula tareas básicas de un pentester: escaneo de puertos TCP con Scapy, pruebas de evasión de firewall (fragmentación, puertos de origen confiables, TTL bajo), crackeo de hashes (MD5/SHA1/SHA256) por diccionario y fuerza bruta, y pruebas de credenciales por SSH (Paramiko) o formularios web.

El “Monitor de Sistema y Keylogger” recopila información del sistema (SO, procesos, red) con psutil, registra pulsaciones de teclado en un hilo de fondo y simula el envío periódico de esa información a un webhook — una demostración didáctica de cómo luce un escenario de exfiltración de datos, pensada exclusivamente para concientización y pruebas en laboratorio propio.

Rol

Investigación + desarrollo en Python

Escaneo y evasión

Paquetes TCP SYN construidos con Scapy para detectar puertos abiertos/cerrados/filtrados, y técnicas de evasión (fragmentación, TTL bajo, puertos de origen 53/80/443) para detectar reglas de firewall débiles.

Crackeo de credenciales

Ataques de diccionario y fuerza bruta limitada sobre hashes MD5/SHA1/SHA256, y pruebas de credenciales por SSH (Paramiko) y formularios web (Requests).

Monitoreo de sistema

Recolección de procesos, conexiones de red y uso de recursos con psutil, guardado periódico en JSON y envío a un webhook de prueba — todo en un entorno propio y controlado.
