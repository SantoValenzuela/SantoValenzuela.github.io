Ualett Go

SaaS + Fintech para conductores: liquidez justa y una billetera por capas.

React NativeReduxNode.jsAWS LambdaGraphQLAWS AuroraStripe

Resumen

Ualett Go es un prototipo desarrollado en un hackatón donde obtuvimos el primer lugar. La propuesta evoluciona una app de logística (viajes/delivery) hacia un ecosistema SaaS + Fintech, con el conductor (gig worker) como eje central: menos incertidumbre, más control y más estabilidad financiera.

El reto no es solo “ganar poco”: es una vulnerabilidad estructural. Los ingresos netos son impredecibles por costos operativos y comisiones, existe una trampa de liquidez entre gastos diarios y cobros semanales, y una opacidad algorítmica que erosiona la confianza. La propuesta plantea pasar de comisiones por viaje a una suscripción mensual accesible más servicios financieros embebidos, apuntando a una retención justa del 70% para el conductor.

Rol

Producto + prototipo full-stack

Billetera de 3 capas

Earned (devengado, retiro inmediato), Stability Buffer (micro-ahorro automático) y Flex Advance (adelantos predictivos según patrones de uso).

Ingresos complementarios

AdTech/SEO interno, alianzas B2B con gasolineras y talleres, y upselling de experiencia (modo silencio, rutas preferenciales).

Stack propuesto

Mobile en React Native + Redux, backend en Node.js sobre AWS Lambda con GraphQL, base de datos AWS Aurora (PostgreSQL), Auth0 con 2FA, KYC con Persona y pagos con Stripe Connect & Treasury.
